# The director's layout sketches

Pictures the director sent as the layout he wants for each page. They are the reference for the UI work of this patch.

## How they are read (director, 2026-11-28)
- **Layout only.** "just the layout": where things sit, what is grouped, how big the parts are. The painted look of the sketches (lantern backgrounds, glossy icons and fish) is the sketch tool's style, not the game's: pages use the game's own drawn art and panels.
- **Ignore the top headers** in the sketches ("Ignore he top headers on these"). The game's own top bar stays.
- **PC first; phones get their own version** of each layout, drawn and shown before it is built.
- Numbers, names and small slips in a sketch are not facts (a sketch shows "Fish Log 1,661 / 1,640", "Pirate's Bay", "The Bluffs").
- Where a sketch shows something the game does differently, it is raised with the director before building, never changed silently (the Cooler's star became a lock; "Filters & Sorting" was not built as a list filter).
