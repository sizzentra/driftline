# The 0.5 list: what the test build has that the live game does not

Written 2026-11-26 (Foundation F5). For the director and Cam to mark. Nothing here is decided.

**Live today:** PC 0.4.8.9.6, phones 0.4.8.9.4: 10 waters, 520 fish, 100 oddities, Tide Pass 50 levels, a small set of Paths.
**Test build 0.4.9:** 20 waters, 1,040 fish, 300 oddities, Tide Pass 100 levels, 15 Paths, and everything below.

**How to mark:** put an x in one box per line, or just send the code with a word ("B8 off").
- **keep** = goes into 0.5 as it is.
- **switch off** = stays in the code, hidden from players for now.
- **remove** = taken out.

**What the tags mean**
- **[SWITCH]** = a switch exists; off is one line, proven today (the game starts clean without it).
- **[SAVES]** = test saves already hold its data. It cannot simply be switched off; taking it out needs real work.
- **[WORK]** = no switch; hiding it needs building first.
- no tag = small enough that keep or remove is an ordinary edit.

How it was checked: the live pages on the `live` branch against the test build's pages, plus the tester notes, the change log and the release notes draft. Where live could not be confirmed, the line says so.
